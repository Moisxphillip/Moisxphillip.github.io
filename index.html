About me

Since discovering the world of game development, I decided to take the path of the code and go further into what it takes to make good game systems. This drove me to a Computer Science major, which exposed me to multiple aspects of this field: low-level programming, project standards, algorithms and efficiency, game engine structure, and finally, game development.

Outside programming, I'm learning 3D modelling and music composition so I can have more tools for building the worlds I've always dreamed about.
